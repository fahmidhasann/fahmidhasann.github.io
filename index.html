Potato Leaf Disease Detector

A machine learning-powered web application for detecting diseases in potato leaves using computer vision. Uses a fine-tuned ResNet18 model to classify potato leaf images into three categories: Early Blight, Healthy, and Late Blight with high accuracy.

Tools: FastAI, PyTorch, ResNet18, Gradio, Computer Vision
