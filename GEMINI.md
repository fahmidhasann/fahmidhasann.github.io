## 4. Key Features & Implementation

### A. Theme System (Dark/Light Mode)
*   **Implementation**: CSS Variables (`--bg-color`, `--text-color`, etc.) are swapped based on the `data-theme` attribute on the `<html>` element.
*   **Persistence**: Uses `localStorage.getItem('theme')` to remember user preference across sessions.
*   **Toggle**: A floating button switches the theme and updates the icon (☀️/🌙).

### B. Project Filtering
*   **Logic**: Located in `initializeProjectFiltering()` in `script.js`.
*   **Mechanism**: Buttons have `data-filter` attributes (all, ai, web, data). Projects have `data-category` attributes. Clicking a filter toggles visibility and opacity for smooth transitions.

### C. Command Palette
*   **Trigger**: `Ctrl + K` or `Cmd + K`.
*   **Functionality**: A hidden modal (`#commandPalette`) allows quick navigation (Home, Projects, Videos) or actions (Toggle Dark Mode).
*   **Search**: Filters commands in real-time as the user types.

### D. Animations
*   **Hero Text**: `Typed.js` cycles through roles (e.g., "AI and Tech Enthusiast").
*   **Scroll Reveal**: `GSAP ScrollTrigger` animates cards (`.project-card`, `.video-card`) up from the bottom as they enter the viewport.
*   **3D Hover**: Custom JS calculates mouse position over cards to apply a 3D perspective rotation (`transform: rotateX(...) rotateY(...)`).

### E. Easter Egg
*   **Konami Code**: Entering `↑ ↑ ↓ ↓ ← → ← → B A` activates a confetti effect using dynamically injected CSS/JS.

## 6. Setup & Deployment
*   **Local Run**: No build step required. Open `index.html` in any browser or run a simple local server (`python -m http.server`).
*   **Deployment**: Simply push to a GitHub repository named `<username>.github.io` to go live via GitHub Pages.

## 7. Customization Guide
*   **Colors**: Edit `:root` variables in `styles.css` (lines 1-17).
*   **Content**: Modify HTML text in `index.html`.
*   **Projects**: Add new `.project-card` divs inside `.projects-grid` in `index.html`. Ensure `data-category` matches the filter buttons.

## 8. Analysis Notes
*   **Code Quality**: Clean, modular vanilla JS. Separation of concerns is well-maintained.
*   **Performance**: Good use of `requestAnimationFrame` (via GSAP) and native CSS transitions.
